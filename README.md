# ⚓ UNCHAINED

The Curse of the Sunken Compass

A cinematic pirate text RPG built in Python.
Break the chains. Or wear them.

🌊 About The Game

UNCHAINED is a narrative-driven, terminal-based RPG where you play a shipwrecked pirate stranded on a cursed island ruled by Davy Jones.

Two colossal sea monsters are imprisoned in eternal conflict.
Ghost crews linger in broken camps.
At the island’s center pulses the Heart of the Locker — the true source of Davy Jones’ power.

Destroy it… and free what it was holding back.

🎮 Gameplay Features

🗺 Room-based exploration system

⚔ Interactive turn-based combat

🐙 Multi-phase boss encounters

🧭 Legendary weapon acquisition (Tidemark Cutlass)

👻 Dialogue-driven NPC system

🌩 Branching endings based on player choice

🎭 Cinematic text engine with dramatic pacing

All gameplay takes place in the terminal using typed commands.

🕹 How to Play
Option 1 — Windows Executable (No Python Required)

Go to the Releases section of this repository

Download UNCHAINED.exe

Double-click to launch

That’s it.

Option 2 — Run From Source

If you prefer running the Python version:

git clone <https://github.com/eugene234466/unchained.git>
cd unchained
python unchained.py

Requires Python 3.x.

No third-party libraries are needed.

⚔ Combat System

During battles, you type your choice:

attack
defend
use

Enemies have unique attack patterns.
Bosses escalate in difficulty.
Strategy matters.

⚓ Story Structure

The game unfolds in three acts:

Act I — Survival
Explore the island. Meet the ghosts. Discover the truth.

Act II — Revelation
Find the Tidemark Cutlass. Confront Davy Jones. Destroy the Heart.

Act III — Ascension or Chaos
Face the Sovereign of Dread and decide the fate of the ocean.

🧠 Technical Overview

Built entirely in Python using:

Structured room dictionaries

Modular NPC handling (dialogue / combat types)

Turn-based battle engine

State-based progression flags

Cinematic text rendering with timed output

Packaged as a standalone Windows executable using PyInstaller.
